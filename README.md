# Inkineers-48mm-Diameter-Compliant-Wheel-Mold
A CAD for a custom compliant wheel used in FIRST Tech Challenge Decode competition 2025-2026. This was tested with Alumilite Amazing Mold Maker and works exceptionally well, although durability is weaker than off-the-shelf options since this was designed to maximize compliance, grip, and flexibility. Feel free to improve it!
